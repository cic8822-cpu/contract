### 핵심 기술 결정사항

**1. HWPX ZIP 처리 전략**
```python
# HWPX는 OpenDocument 기반 ZIP
# content.xml, styles.xml, settings.xml 포함
# 각 XML 파일에서 {{PLACEHOLDER}} 정규식으로 검색/치환
# 원본 구조 보존: 새로운 임시 디렉토리에 복사 후 처리
```

**2. 플레이스홀더 매칭**
```python
# 정규식: r'\{\{([A-Za-z0-9_가-힣]+)\}\}'
# Excel 칼럼명 ↔ HWPX 플레이스홀더 자동 매핑
# 대소문자/언더스코어 정규화 필요
```

**3. 에러 처리 계층**
```
사용자 입력 검증
  ↓
Excel 칼럼 / HWPX 플레이스홀더 매핑 검증
  ↓
Dry-run (실제 생성 전 시뮬레이션)
  ↓
배치 생성 (에러 발생 시 부분 롤백)
```

**4. 인코딩 안전성**
```python
# HWPX XML은 UTF-8
# Excel도 UTF-8로 읽음
# 파일명: CP949 또는 UTF-8 조심스럽게 처리
```

## 📝 상세 요구사항

### 필수 요구사항

1. **Excel 파일 처리**
   - `.xlsx` 파일 읽기 (openpyxl 사용)
   - 첫 행을 칼럼명으로 인식
   - 각 행을 1개 계약서로 변환
   - 30행 입력 → 30개 출력 파일 생성

2. **HWPX 플레이스홀더 치환**
   - HWPX를 ZIP으로 열기
   - 내부 모든 XML/텍스트 파일 검색
   - `{{FIELD_NAME}}` 형식의 플레이스홀더 식별
   - Excel 칼럼명과 자동 매핑
   - 플레이스홀더를 해당 값으로 치환
   - 수정된 내용을 새로운 HWPX로 다시 압축

3. **파일명 자동 생성**
   - 사용자가 선택한 칼럼 (예: "이름")을 파일명 기준으로 사용
   - 예: `이름` 칼럼이 "김철수"면 → `김철수.hwpx`
   - 빈값이거나 선택 칼럼 없으면 → `row_1.hwpx`, `row_2.hwpx`
   - 파일명 중복 시 → `김철수_1.hwpx`, `김철수_2.hwpx`

4. **GUI (비개발자 친화)**
   - 메인 창: 파일 선택 버튼 (Excel, 템플릿)
   - 출력 폴더 선택
   - "문제 진단" 버튼 → Dry-run 검증 결과 표시
   - "생성 시작" 버튼 → 배치 처리 (프로그레스 바)
   - 로그 출력 영역 (진행 상황, 에러)
   - 완료/에러 요약 팝업

5. **검증 (Dry-run)**
   - Excel 칼럼명 추출
   - HWPX 내 모든 플레이스홀더 추출
   - 매핑 가능 여부 분석
   - 누락된 칼럼 / 미사용 플레이스홀더 목록 표시
   - 실제 생성 전 사용자가 확인할 수 있도록

6. **에러 처리 (모두 포함)**
   - Excel 파일 손상 → 명확한 에러 메시지
   - HWPX 파일 유효하지 않음 → 복구 불가 메시지
   - 필수 칼럼 누락 → 어떤 칼럼이 없는지 명시
   - 빈 값 → 경고하고 빈 문자열로 치환 (또는 스킵 옵션)
   - 파일 권한 문제 → "출력 폴더를 확인하세요" 메시지
   - 디스크 용량 부족 → 경고

7. **파일 보존**
   - 원본 Excel 파일 → 읽기 전용, 수정 안함
   - 원본 HWPX 템플릿 → 절대 수정 안함
   - 모든 처리는 임시 폴더에서 진행 후 최종 출력 폴더로 복사

## ⚠️ 제약사항 및 주의사항

- **오프라인**: 인터넷 연결 불필요, 모든 처리 로컬
- **HWPX 보존**: 원본 포맷, 서식, 이미지 손상 방지

  - 주의: XML 정규식 치환 시 태그 구조 훼손 금지
  - 안전한 접근: XML 파서로 노드 단위 처리
- **한글 인코딩**: UTF-8 일관성 유지
- **파일명**: Windows 예약어 제외 (CON, LPT, PRN 등)
- **메모리**: 대용량 Excel (10,000행+) 시 청크 처리
- **Hancom Office 불필요**: HWPX는 ZIP이므로 직접 처리 가능

### 2. 플레이스홀더 추출

```python
import re

def extract_placeholders(text: str) -> Set[str]:
    """{{이름}}, {{주소}} 형식의 플레이스홀더 추출."""
    pattern = r'\{\{([A-Za-z0-9_가-힣]+)\}\}'
    return set(re.findall(pattern, text))

def replace_placeholder(text: str, data: Dict[str, str]) -> str:
    """플레이스홀더를 값으로 치환."""
    for key, value in data.items():
        placeholder = f"{{{{{key}}}}}"
        text = text.replace(placeholder, value or "")
    return text
```
