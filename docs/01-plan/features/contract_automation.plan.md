# [Plan] 신규채용자 계약서 작성 자동화

- **기능명**: 신규채용자 계약서 작성 자동화
- **상태**: 계획 완료
- **작성일**: 2026-03-06
- **담당**: bkit (AI Agent)

## 계획 내용
사용자가 엑셀 파일과 한글 계약서 양식을 선택하면, 엑셀의 인적사항을 한글 문서의 해당 필드에 자동으로 채워넣어 개인별로 저장하는 프로그램을 개발함. 

## 구현 전략
1. **데이터 소스**: pandas를 이용해 엑셀 로드
2. **자동화 엔진**: pyhwpx(한컴 API)를 사용하여 서식 손상 없는 데이터 입력
3. **UI**: tkinter를 사용하여 직관적인 파일 선택 환경 제공
4. **배포**: PyInstaller로 EXE화하여 범용성 확보
