## 프로젝트 개요

### 목표

비개발자가 Excel 데이터와 HWPX 계약서 템플릿을 입력하면, 자동으로 다중 개별 계약서 HWPX 파일을 생성하는 GUI 기반 Windows EXE 프로그램을 개발합니다.

- 각 Excel 행은 1개의 독립적인 HWPX 문서를 생성
- {{이름}}, {{주소}} 같은 플레이스홀더를 해당 칼럼 값으로 자동 치환
- 원본 템플릿 및 Excel 파일 보존
- 오프라인 완전 독립 실행

### 핵심 특징

| 특징 | 설명 |
|------|------|
| **배치 처리** | Excel 행 단위로 다중 HWPX 파일 자동 생성 |
| **플레이스홀더 치환** | {{FIELD_NAME}} 형식의 동적 값 치환 |
| **GUI 기반** | 비개발자도 쉽게 사용 가능 |
| **에러 처리** | All-or-nothing (첫 에러에서 배치 중단) |
| **Dry-run** | 실제 생성 전 검증 및 사전 점검 |
| **파일 안전성** | 원본 파일 보존, 임시 폴더에서 안전한 처리 |

## 요구사항 명세

### 필수 요구사항

#### 1. Excel 파일 처리
- `.xlsx` 파일 읽기 (openpyxl 사용)
- 첫 행을 칼럼명으로 인식
- 각 행을 1개 계약서로 변환
- 대용량 Excel (10,000행+) 청크 처리 지원

#### 2. HWPX 플레이스홀더 치환
- HWPX를 ZIP으로 열기
- 내부 모든 XML 파일 (content.xml, styles.xml 등) 검색
- `{{FIELD_NAME}}` 형식의 플레이스홀더 식별
- Excel 칼럼명과 자동 매핑
- **XML 파서 사용** (ElementTree)으로 노드 단위 처리
- 플레이스홀더를 해당 값으로 안전하게 치환
- 수정된 내용을 새로운 HWPX로 다시 압축

#### 3. 파일명 자동 생성
- **사용자 선택 방식** (GUI에서 선택)
  - 옵션 1: 특정 칼럼 사용 (예: "이름" 칼럼)
  - 옵션 2: 행 번호 사용 (row_1.hwpx, row_2.hwpx)
- 선택 칼럼 사용 시 중복 처리: `김철수_1.hwpx`, `김철수_2.hwpx`
- 빈값이거나 선택 칼럼 없으면 행번호로 폴백

#### 4. GUI (중간 수준)
**기본 기능:**
- 메인 창: 파일 선택 버튼 (Excel, 템플릿)
- 출력 폴더 선택
- "문제 진단" 버튼 (Dry-run 검증 결과 표시)
- "생성 시작" 버튼 (배치 처리)
- 로그 출력 영역 (진행 상황, 에러)
- 완료/에러 요약 팝업

**편의 기능:**
- 파일명 칼럼 선택 UI
- 마지막 선택 파일 경로 저장 (JSON 설정)
- 생성 완료 후 출력 폴더 자동 열기 (옵션)

#### 5. 검증 (Dry-run)
- Excel 칼럼명 추출
- HWPX 내 모든 플레이스홀더 추출
- 매핑 가능 여부 분석
- 누락된 칼럼 / 미사용 플레이스홀더 목록 표시
- 실제 생성 전 사용자가 확인할 수 있도록 팝업 표시

#### 6. 에러 처리
- **All-or-Nothing 방식**: 첫 번째 에러 발생 시 전체 배치 중단
- Excel 파일 손상 감지 → 명확한 한글 에러 메시지
- HWPX 파일 유효하지 않음 → 복구 불가 메시지
- 필수 칼럼 누락 → 어떤 칼럼이 없는지 명시
- 빈 값 → **그대로 놔두기** (플레이스홀더 → 아무것도 안 나타남)
- 파일 권한 문제 → "출력 폴더를 확인하세요" 메시지
- 디스크 용량 부족 → 경고 메시지

#### 7. 파일 보존
- 원본 Excel 파일 → 읽기 전용, 수정 안함
- 원본 HWPX 템플릿 → 절대 수정 안함
- 모든 처리는 임시 폴더에서 진행 후 최종 출력 폴더로 복사

### 선택적 요구사항 (미구현)

- HWPX 내 이미지 포함 문서에 대한 안전성 검증
- 배치 작업 취소 기능
- 로그 파일 자동 저장

## 설계 결정사항

### 1. 에러 처리 전략: All-or-Nothing
**결정:** 첫 번째 에러 발생 시 전체 배치 중단  
**이유:** 사용자에게 명확한 상태 보장, 부분 성공으로 인한 혼동 방지  
**구현:** 배치 루프에서 예외 발생 시 즉시 중단, 롤백 처리

### 2. 빈 값 처리: 그대로 놔두기
**결정:** 빈값 셀은 플레이스홀더를 아무것도 안 나타나게 처리  
**이유:** 사용자가 선택적 필드를 명시적으로 비워둔 것으로 간주  
**구현:** `value or ""` 형태로 빈 문자열 치환

### 3. 파일명 생성: 사용자 선택
**결정:** GUI에서 "칼럼 사용" 또는 "행번호 사용" 선택 가능  
**이유:** 다양한 사용 사례 대응, 유연성 제공  
**구현:**
- 칼럼 선택 시: `df[selected_column].apply(normalize_filename)`
- 중복시: `김철수_1.hwpx`, `김철수_2.hwpx`
- 빈값: `row_{idx}.hwpx` 폴백

### 4. XML 처리: ElementTree 파서
**결정:** XML 파서 사용 (정규식 X)  
**이유:** 서식/이미지 손상 방지, 안전성 우선  
**구현:**
```python
import xml.etree.ElementTree as ET
tree = ET.parse(xml_path)
root = tree.getroot()
# 노드 단위로 텍스트 처리
for elem in root.iter():
    if elem.text:
        elem.text = replace_placeholder(elem.text, data)
```

### 5. 로그 저장: 메모리 기반
**결정:** 로그 파일 저장 안함, 메모리에만 유지  
**이유:** 간단한 구현, 사용자 홈 디렉토리 오염 방지  
**구현:** loguru 핸들러를 StringIO에 저장, 세션 종료시 자동 삭제

### 6. 대용량 파일 처리: 청크 처리
**결정:** 청크 단위로 Excel 읽기 (메모리 효율)  
**이유:** 10,000행+ 대용량 파일 지원  
**구현:** openpyxl의 `iter_rows()` 또는 청크 배치 처리

### 7. 설정 저장: JSON 파일
**결정:** 사용자 홈 디렉토리에 JSON으로 저장  
**경로:** `~/.contract_generator/settings.json`  
**내용:** 마지막 선택 파일 경로, 파일명 칼럼 선택값  
**구현:** `pathlib.Path.home()` 사용

## 데이터 흐름

### 사용자 상호작용 플로우

```
1. [메인 창] 파일 선택
   ├─ Excel 파일 선택 (.xlsx)
   ├─ 템플릿 HWPX 선택 (.hwpx)
   ├─ 출력 폴더 선택
   └─ 파일명 칼럼 선택 (칼럼 또는 행번호)

2. [검증] 문제 진단 버튼 클릭
   ├─ Excel 칼럼 읽기
   ├─ HWPX 플레이스홀더 추출
   ├─ 매핑 분석
   └─ 결과 팝업 표시

3. [생성] 생성 시작 버튼 클릭
   ├─ 최종 검증
   ├─ 배치 처리 루프
   │  ├─ 각 행 반복
   │  ├─ 임시 폴더에서 HWPX 생성
   │  ├─ 최종 출력 폴더로 복사
   │  └─ 진행률 UI 업데이트
   ├─ 완료/에러 요약 팝업
   └─ 출력 폴더 자동 열기 (옵션)
```

### 배치 처리 세부 흐름 (All-or-Nothing)

```
FOR each row in Excel:
    TRY:
        1. 임시 디렉토리 생성
        2. HWPX ZIP 추출
        3. XML 파일들 파싱
        4. 플레이스홀더 치환
        5. XML 저장
        6. 새로운 HWPX 압축
        7. 최종 출력 폴더로 복사
        8. 로그 기록 (✓)
    EXCEPT Exception as e:
        1. 로그 기록 (✗)
        2. 배치 중단 (All-or-Nothing)
        3. 에러 팝업 표시
        4. RETURN
```

## 에러 처리 전략

### 에러 계층 (위에서 아래로 검증)

   ├─ Excel 파일 선택 (존재, 읽기 가능)
