# 제품 요구사항 정의서 (PRD) - 신규채용자 계약서 작성 자동화

## 1. 개요
신규 채용되는 교육공무직원의 기초 정보를 엑셀에서 읽어, 한글(HWPX) 계약서 양식의 지정된 위치에 자동으로 입력하고 개인별 파일로 생성하는 시스템입니다.

## 2. 목표
*   **정확성**: 엑셀 데이터와 계약서 내용 간의 100% 일치 보장
*   **효율성**: 수작업으로 수십 장의 계약서를 만드는 시간을 1분 내외로 단축
*   **편의성**: 코딩 지식이 없는 사용자도 GUI를 통해 쉽게 사용 가능
*   **배포성**: 파이썬 설치 없이 실행 가능한 EXE 파일 제공

## 3. 주요 기능
### 3.1 엑셀 데이터 파싱
*   1행 헤더(순, 직종, 수험번호, 이름, 생일, 전화, 임용일, 주소 등) 분석
*   데이터 행별로 딕셔너리 리스트 생성

### 3.2 한글(HWPX) 문서 자동화
*   `pyhwpx`를 사용하여 양식 내 `{{이름}}` 등 템플릿 변수 치환
*   또는 누름틀(Field)이 있는 경우 필드명 매핑 지원 (안정성 위해 `put_field_text` 권장)
*   개인별 저장 규칙: `[임용일] 직종-이름-계약서.hwp`

### 3.3 사용자 인터페이스 (GUI)
*   엑셀 파일 선택 버튼
*   한글 양식 파일 선택 버튼
*   저장 경로 선택 버튼
*   진행률(ProgressBar) 표시 및 완료 메시지

### 3.4 배포 (EXE)
*   PyInstaller를 이용한 단일 실행 파일 생성

## 4. 기술 요구사항
*   Python 3.10+
*   pyhwpx (한컴오피스 설치 환경 필요)
*   pandas, openpyxl (엑셀 처리)
*   tkinter (GUI)

## 5. 성공 지표
*   10명의 샘플 데이터를 넣었을 때 10개의 정확한 계약서가 생성되는가?
*   생성된 파일이 한글 프로그램에서 정상적으로 열리는가?
*   EXE 파일이 다른 PC에서 실행되는가?
