## 📋 HWPX 템플릿 작성 방법

**중요**: 템플릿에 플레이스홀더 추가해야 합니다!

### 올바른 형식 예시

한글 문서에서 이렇게 작성:
```
신규채용자 근로계약서

계약자명: {{근로자성명}}
직종: {{직종}}
급여: {{급여}}
계약기간: {{기간}} ~ {{계약일자}}
학교명: {{학교명}}
근무 주소: {{주소}}
사용자: {{사용자성명}}
```

### 플레이스홀더 이름
현재 템플릿의 플레이스홀더:
```
{{근로자성명}}   - 근로자 이름
{{직종}}         - 직업 종류
{{급여}}         - 급여액
{{기간}}         - 계약기간
{{계약일자}}     - 계약 날짜
{{학교명}}       - 학교/기관명
{{주소}}         - 주소
{{사용자성명}}   - 사용자(계약담당자) 이름
```

### 중요한 점
- ✅ 영문 중괄호 사용: `{{변수}}`
- ❌ 한글 중괄호 사용 금지: `｛｛변수｝｝`
- ✅ 플레이스홀더는 정확한 이름
- ❌ 공백 추가 금지: `{{ 변수 }}`

## ❓ 자주 묻는 질문

### Q. 플레이스홀더가 여전히 발견되지 않습니다
**A.** 템플릿에 `{{변수명}}` 형식으로 정말 작성되어 있는지 확인하세요.
- 더블 중괄호인가? `{{`와 `}}`
- 공백이 없나? `{{변수}}` (O), `{{ 변수 }}` (X)
- 한글 중괄호는 아닌가? `｛｛변수｝｝` (X)

### Q. Excel 칼럼을 어떻게 설정하나요?
**A.** Excel의 첫 행에 칼럼 이름을 입력하세요.
- 칼럼명이 템플릿의 `{{칼럼명}}`과 정확히 일치해야 합니다.

### Q. 여러 계약서를 한 번에 만들 수 있나요?
**A.** 네, Excel에 여러 행을 입력하면 일괄 생성됩니다.
- 1행 = 헤더
- 2행 이상 = 데이터
- 각 행마다 하나의 계약서 생성

### Q. 생성 중 오류가 나면?
**A.** 배치파일 실행 시 오류 메시지를 확인하세요.
- 문제가 해결되지 않으면 로그 파일을 확인하세요.
